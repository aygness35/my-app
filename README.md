# 🪩 Eventify - Etkinlik & Bilet Platformu

Bu proje **React + TypeScript + Vite + Tailwind CSS** kullanılarak geliştirilmiştir. Projeyi kendi bilgisayarınızda yerel olarak çalıştırmak ve geliştirmek için aşağıdaki adımları sırasıyla uygulayabilirsiniz.

---

## 🚀 Başlangıç ve Kurulum

Projede çalışmaya başlamak için terminalinizi açın ve sırasıyla şu komutları çalıştırın:

### 1. Projeyi Kendi Bilgisayarınıza Çekin (Clone)

```bash
git clone [https://github.com/aygness35/my-app.git](https://github.com/aygness35/my-app.git)
cd my-app
```

2. Gerekli Paketleri Yükleyin
   Projenin ihtiyaç duyduğu bağımlılıkları ve kütüphaneleri yüklemek için:

Bash
npm install

3. Projeyi Yerel Sunucuda Çalıştırın
   Bash
   npm run dev
   Komutu çalıştırdıktan sonra terminalde çıkan adrese (örneğin http://localhost:5173) tıklayarak uygulamayı tarayıcınızda görüntüleyebilirsiniz.

🔄 Birlikte Çalışma & Git İş Akışı (Git Workflow)
Geliştirme yaparken çakışma (conflict) yaşamamak için şu adımlara dikkat edebilirsiniz:

🛠️ Çalışmaya Başlamadan Önce (Kodları Güncelleme)
Projeyi açıp yeni bir şey eklemeden önce mutlaka en güncel kodları kendi bilgisayarınıza çekin:

Bash
git pull
📤 Değişiklik Yaptıktan Sonra (Kodları Gönderme)
Yeni bir özellik ekledikten veya düzenleme yaptıktan sonra değişiklikleri GitHub'a göndermek için:

Bash
git add .
git commit -m "Yapılan değişikliğin açıklaması"
git push
🛠️ Kullanılan Teknolojiler
Frontend: React, TypeScript, Vite

Styling: Tailwind CSS

Routing: React Router DOM

---
